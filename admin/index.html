Architecture d'Hébergement & Backend PHP (cPanel)

Comment déployer la version complète avec base de données MySQL sur un serveur web en ligne

ℹ️ Deux modes d'administration disponibles :
  • Mode Local Node.js (actuel) : Cette console d'administration gère directement data.json et data.js sans avoir besoin d'installer PHP ou Apache sur votre machine.
  • Mode Production cPanel / Apache : Le dossier /admin/ contient déjà tous les scripts PHP prêts (index.php, install.php, formations.php, config.php) pour un déploiement avec base de données MySQL sur votre hébergement cPanel marocain.

Étapes de déploiement sur cPanel / meplus.ma :

  1. Transférez l'ensemble des fichiers du projet via FTP ou le Gestionnaire de fichiers cPanel dans le dossier public_html/.
  2. Créez une base de données MySQL dans l'interface cPanel (ex: meplus_db) et un utilisateur associé avec tous les privilèges.
  3. Éditez admin/config.php pour y renseigner vos identifiants de base de données : 
    define('DB_HOST', 'localhost');
define('DB_NAME', 'votre_db');
define('DB_USER', 'votre_user');
define('DB_PASS', 'votre_motdepasse');
  4. Ouvrez dans votre navigateur https://meplus.ma/admin/install.php pour initialiser automatiquement les tables et importer les 85 formations en 1 clic !
  5. Connectez-vous ensuite à https://meplus.ma/admin/login.php avec l'utilisateur par défaut admin / admin123#.
